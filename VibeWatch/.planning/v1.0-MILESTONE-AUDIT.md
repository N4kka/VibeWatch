## Integration Findings

### ⚠ Critical: BUG-03 Double-Handler Conflict

**Requirement affected:** BUG-03
**Break location:** `VibeWatchApp/App/VibeWatchApp.swift:58` vs `VibeWatchApp/App/MainTabView.swift:218`

```
Flow: SmartNotificationService.handleNotificationTap()
        → AppNavigationManager.deepLinkTarget = target
          → VibeWatchApp.swift:58  .sheet(item: $appNavigationManager.deepLinkTarget)  [fires]
          → MainTabView.swift:218  .onChange(of: navigationManager.deepLinkTarget)      [fires]
              → handleDeepLinkTarget() → clearDeepLinkTarget() [nilifies target]
                  → dismisses sheet from step above immediately
```

**Fix:** Remove `.sheet(item: $appNavigationManager.deepLinkTarget)` from `VibeWatchApp.swift` line 58. Phase 1 chose in-stack navigation via `navigationDestination(item: $selectedMovie)`; the pre-existing modal sheet was not removed.

### ⚡ Noted: PERF-01 Dual Cache Mismatch

`AppState.loadCachedContentSync()` sets `isPreloading = false` on SQLite hit, but `MainTabView.waitForDiscoveryContentReady()` independently polls `ContentCacheManager` (in-memory) with a 3-second timeout. Splash exit may be delayed even when SQLite personalized cache is populated.

### ✓ BUG-01: Supabase Migration Deployment Required

Code is complete. Migration file `20260305000000_add_clip_comments_updated_at.sql` committed. Requires `supabase db push` before comments sync works on Cloud. Local SQLite migration 3 runs automatically via `DatabaseMigrationManager`.
